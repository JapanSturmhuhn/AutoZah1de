# AutoZah1de

by **JapanSturmhuhn** ⭐

### ----

运行此程序后，每次您（重新）启动电脑时都会打开一个 ZAH1DE 播放列表，这样您就可以随时准备好美妙的音乐！

after running this program, a ZAH1DE playlist will open every time you (re)start your PC, so you always have good music ready!😊
